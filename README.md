# 📚 Perpustakaan Sekolah - Blogger Template

[![Blogger](https://img.shields.io/badge/Platform-Blogger-orange?style=flat-square&logo=blogger)](https://www.blogger.com)
[![License](https://img.shields.io/badge/License-MIT-blue.svg?style=flat-square)](LICENSE)
[![Status](https://img.shields.io/badge/Status-Active-success.svg?style=flat-square)]()

Tema Blogger (XML) yang dirancang khusus untuk website perpustakaan sekolah. Tema ini difokuskan untuk memudahkan sekolah dalam menampilkan katalog buku, informasi fasilitas perpustakaan, kegiatan literasi, dan pengumuman secara profesional dan modern.

👁️ **[Lihat Live Demo](https://demoperpustakaansekolah.blogspot.com/)**

---

## ✨ Fitur Unggulan

- **Responsive Design:** Tampil optimal di berbagai perangkat (Desktop, Tablet, dan Smartphone).
- **SEO Friendly:** Struktur kode yang dioptimalkan untuk mesin pencari.
- **Fast Loading:** Ringan dan memuat halaman dengan cepat.
- **Katalog Buku:** Desain postingan yang disesuaikan untuk menampilkan detail buku (Judul, Pengarang, Penerbit, Sinopsis).
- **Mudah Disesuaikan:** Pengaturan tata letak (Layout) langsung dari dashboard Blogger tanpa perlu mengedit kode XML secara manual.
- **Cross-Browser Compatible:** Berjalan lancar di Chrome, Firefox, Safari, dan Edge.
- **Widget Pendukung:** Dilengkapi widget pencarian, postingan terbaru, dan kategori/label buku.

## 🚀 Cara Pemasangan (Instalasi)

1. **Download Tema:** Unduh file `tema-perpustakaan.xml` dari repository ini (atau menu Releases).
2. **Login ke Blogger:** Masuk ke dashboard Blogger Anda.
3. **Pilih Menu Tema (Theme):** Di panel sebelah kiri, klik menu **Tema**.
4. **Backup Tema Lama:** Sangat disarankan untuk mem-backup tema lama Anda. Klik ikon dropdown (panah ke bawah) di sebelah tombol "Sesuaikan" > pilih **Cadangkan**.
5. **Upload Tema Baru:** Klik dropdown lagi > pilih **Pulihkan** > klik **Upload** dan pilih file `tema-perpustakaan.xml` yang sudah diunduh.
6. **Selesai!** Buka blog Anda untuk melihat tampilan baru.

## ⚙️ Pengaturan Kustom

Untuk mengatur menu navigasi, logo, dan widget lainnya:

1. Buka dashboard Blogger.
2. Pergi ke menu **Tata Letak (Layout)**.
3. Edit widget yang tersedia (seperti _Header_, _Main Menu_, atau _Sidebar_) sesuai dengan kebutuhan perpustakaan sekolah Anda.
